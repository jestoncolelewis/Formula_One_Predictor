# The Formula One Predictor
### Final project for Bachelor's of Science in Computer Science at WGU by Jeston Cole Lewis
The view a running version of this project, visit [this](https://f1-predictor.streamlit.app/).

## Build on your machine
1. Ensure Python 3.11 is installed on your machine
2. Ensure pip is installed and working
3. Ensure graphviz is installed
4. Open a terminal
5. In your terminal `cd` into the director for the Formula One Predictor
6. Run the command `bash setup.sh`
7. After all requirements are installed, run the command `streamlit run sreamlit_app.py`
8. Navigate to your browser
